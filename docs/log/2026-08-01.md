## 浏览器验证：两次误诊，最后靠 Playwright 才走通

第一次尝试用内置 Browser pane 上传文件，卡死在没有弹窗也没有报错。诊断成
`document.hidden === true` 导致 React 推迟水合——**这个诊断是错的**，换真实
Playwright 浏览器后同样复现。真正原因是 `setInputFiles` 只要元素存在就成功，
**不等** React 装上 `onChange`；水合前设的文件被塞进 input 却没人在听，而重试
救不回来——**再选同一个文件不会再发 `change` 事件**，循环死锁。修法是每次
重试前先 `setInputFiles([])` 清空。

修完之后写了 9 项本地 e2e（`homework-import.spec.ts`），真选文件、真走
Server Action、真打后端，覆盖 UTF-8/GBK/传错文件/表头警告/幂等/17 行长清单不被
裁切。中途还抓到测试自己的两个假阳性：标记的是**跳过清单**里的人（不影响确认
条数，功能坏了这条也照样绿）；以及断言了错误的「将跳过」计数（漏算了讲师本人）。
