## course-catalog（六组，evaluator 100 / 100 / 89 / 98 / 100 / 100）

三张表 + 课程页 + 弹窗与行内排课。报课仍未做，是下一个 change。

**几个定下来的形状**

- **别名表主键就是归一化后的别名** → 全库唯一由结构保证，应用层不需要"先查再写"。
  另加 CHECK 约束兜底绕过 API 的直写脚本（与 `students_email_lower_key` 同源）。
- **场次存墙上时间 + IANA 时区名，绝对时刻读取时派生。** 讲师说的"美西 7:30"在换季前后都是 7:30；
  时刻是派生物，不入库，因为时区规则本身会改。
- **"墙上时间→时刻"这步只在 Python 里做。** JS 没有原生 API，通用做法是拿 `Intl` 试探偏移再迭代，
  是本 change 最容易写错的一段——不该在前后端各写一遍。前端只 `Intl` 格式化一个已知时刻。
- **状态 = 派生 + 可覆盖三态**，`state_override` 为 null 即"跟随日期"。一个 state 列表达不了第三态。
  "今天"取 `America/Los_Angeles`：服务器在 UTC，按它算会在每天那几个小时里把今晚的课提前标成已上。
- **侧栏改成真路由**（`setView` → `next/link`），课程页独立取数。塞进 `StudentsClient` 会让那个组件
  同时持有两套数据，且打开学员名单要顺带查课程表。

## evaluator 抓到我五处自己没看见的问题

全是同一类：**失败信息丢失**。

1. 别名归属守卫没有测试（group 3）——那类守卫会静默退化。
2. **场次写入失败只渲染在课程弹窗里，而行内编辑时弹窗是关的**：保存失败什么都不说，界面看着像存上了。
3. 我修完 2 之后，同一个毛病在"新建课程提交即关窗"上又出现。
4. 再修完，"保存中点取消"是第三个出口。
5. 别名按钮没被 `busy` 挡住，连点把同一个别名发两遍、第二次撞主键。

共同形状是**失败信息与承载它的组件生命周期脱钩**。已沉淀成 CLAUDE.md 的一条：
关闭/收起只在成功回调里做、写入期间禁用所有出口（含取消）、错误按对象分开存；
测试要用挂住不 resolve 的 promise 断言 `disabled`，只断言最终态的测试对这类回归全盲。

## 自己制造的一个坑

为截图在本地建了一门带别名 `S1` 的课，之后 **20 个后端测试变红** ——
别名全库唯一，测试再插 `S1` 就 409，而测试本身在回滚事务里，看不出是外部数据造成的。
改成测试开始时于同一事务内清空课程三张表；**没有改用随机别名**，因为"别名撞了"本身就是被测行为。

## 验收标准我自己写错过一次

原本让夏令时测试比"美西 vs 美东"——美国两地同日切换，恒差 3 小时，那条断言无论实现对错都通过。
改成比**上海**（中国不用夏令时，时差在 15/16 小时之间跳）：两场同为美西 19:30、
一场 10 月一场 12 月，上海分别是次日 10:30 与 11:30。生产实测两场都对。

## 其它踩到的

- `SQLModel` 把显式 `None` 发成 SQL NULL，盖掉列的 DB 默认值 → `created_at` 报 NotNullViolation。
  应用不读不写的列干脆不映射。
- Playwright 的 `waitUntil: "networkidle"` 在会冷启动的后端上可能永远不达成，
  报错却指向后面那个 `waitFor`，看着像页面没渲染。改用 `domcontentloaded` + 等只有数据到位才出现的文案。

## course-scheduling-fields（同日下午）

准备把真实课程从 course-portal 导入生产，结果**导入前就卡住了**：刚上线的 `course-catalog`
有两个字段存不下真实数据，而两处的根因相同 —— 我把设计稿里的**示例值**当成了真实约束。

- 稿上画了 1/2/3/4 小时四个 chip → 列成了 `hours int` 限 1–4。四门真实课程**全是 150 分钟**。
- 稿上写着「时间（美西）」→ 美西成了 schema 默认值与换算基准。四门课**全排在 8:30 PM 美东**。

数据库那层其实没问题（`tz` 一直是每场自己的字段），卡住的是界面：讲师要录美东的课，
得自己先把 20:30 换算成 17:30 —— 而「不用手算时区」正是这个功能存在的理由。

**改动**：`hours` → `duration_minutes`（替换不并存，migration 回填 `hours*60`）；
课程加 `default_tz`（只作新增场次的预选，**不回溯**已有场次）；
新增/编辑场次可选时区，标签跟随；时长从 chip 改成分钟输入。

**编辑态那个 chip 的初始值是本次最容易写错的地方**：必须取**该场自己的 tz**，不是课程默认。
取错的后果特别隐蔽 —— 打开一个美西的旧场次再保存，它就被改成了课程默认时区，
时间数字看着没变，实际差三小时。为它单写了一条测试。

## 这一轮踩到的四个坑（已进 CLAUDE.md）

1. **设计稿的示例值 ≠ 取值域**。实现枚举/范围字段前先拿一条真实数据比对。
2. **openspec 的 MODIFIED 按标题匹配**：delta 里改了需求标题 → `archive` 报 header not found 并
   **整次回滚**。行为变了就该改标题，正确表达是 REMOVED（旧标题 + Reason/Migration）+ ADDED（新标题）。
3. **pytest fixture 每次新建 engine 不 dispose**，第 ~100 个测试起 Postgres 拒绝连接，
   而报错落在一个**不相干**的测试的 setup 上。engine 提到模块级即可（顺带快一倍）。
4. **migration 的回填在本地永远跑在 0 行上** —— `db reset` 是空库重放。绿灯不代表回填写对了，
   真实证据只能来自生产既有数据，所以这类 migration 的生产验收要专列一条。

## 验收

生产 migration workflow 绿；那门占位课程时长显示 `120 分钟`（`hours=2` 正确回填）；

## course-list-order（同日傍晚，evaluator 99 / 99）

讲师试用报两处：课程列表成了上下堆叠（设计稿是左右），以及顺序应按第一次开课时间倒序。
后者在 `course-catalog` 的 spec 里本就留白，这次补上：未排课的排最前，同日以名称与 id 兜底。

倒序用**反转日期字符串**而不是 `sorted(reverse=True)` —— 后者会把名称兜底也反过来，
同日两门课的顺序就与"名称升序"相反。未排课优先用**分组位**而不是哨兵日期。

布局那条不进 spec（视觉基准是设计稿）。VISUAL DIFF 时按导览要求临时造了 10 门课，
确认左栏内部滚动（内容高 961 / 可视 679）而不是把详情往下推 —— 上一版正是"四门课看着挺好"让漂移过了关。

清理那 10 门课时我的 KEEP 名单破折号写成 `——` 而真实数据是 `—`，误删了本地 S2/S4，
`supabase db reset` + 重启后端 + 重跑 `tools/course-import` 恢复。只动本地库。
顺带发现：**课程没有删除端点**（有意设计，下线走 `offline`），所以我那几个 DELETE 是静默 404。

## course-page-boundaries（同日晚，evaluator 98 / 99 / 95）

讲师报「切换左侧 tab 感觉刷新有点问题」。生产实测三态：点后 250ms 旧页不动、
然后整屏加载卡片（侧边栏一起消失）、600ms 才出新页与新高亮。三个症状同源 ——
**`Sidebar` 由每个 page 各自渲染**，于是 `loading/error` 只能整屏替换、高亮只能等页面渲染完。

改法：路由组 `app/(app)/` 承载共享 layout，六个页面迁入；高亮改 `usePathname` 派生；
徽标计数以 `<Suspense>` 隔离；补课程页 `loading.tsx` 与两层 `error.tsx`。

**最重要的一件事是 VISUAL DIFF 发现的，不是测试发现的。** 停掉本地后端后整个外壳死掉、
掉到根错误页、侧边栏消失 —— 因为 `(app)/error.tsx` 接不住同段 layout 自己抛的错，
而计数是 layout 渲染的。这恰好发生在冷启动，也就是这套边界存在的理由本身。
修法是计数的 rejection 就地吞掉，未知计数渲染 `—`。

实测掉了两个原本只能靠猜的问题：`revalidatePath` **不需要**路由组前缀（真实新建学员，徽标 10 → 11）；
layout 与 page **没有**合并同名 GET（一次硬加载打后端 3 次，各带不同的 `AbortSignal.timeout()`）。

生产验收等了 17 分钟让 Render 免费档进入休眠，才验到冷启动路径：
`/courses` 2190ms 内出加载卡片，同一时刻 `/enroll` 仍能打开（这条同时证明 Suspense 没漏包）。

四条已进 CLAUDE.md：error 边界接不住同段 layout；layout 未隔离取数阻塞每次导航且无任何征兆；
`revalidatePath` 粒度与路径两种错法症状相同；`vi.clearAllMocks()` 不清 mock 实现。
